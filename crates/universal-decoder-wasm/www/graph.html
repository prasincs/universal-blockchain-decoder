About This Visualization

Inspired by Echonest's music relationship graphs, this visualization shows blockchain chains as nodes in a network, connected by their relationships:

  • Fork Relationships (red): Direct forks like Bitcoin → Bitcoin Cash → Bitcoin SV
  • Shared Decoders (blue): Chains using the same generic decoder (e.g., 2000+ EVM chains)
  • Technology Sharing (purple dashed): Shared frameworks like OP Stack or Cosmos SDK

The force-directed layout naturally clusters related chains together. Larger nodes represent more significant chains (mainnets, high TVL). Node colors indicate chain family (UTXO, Account, Instruction, Privacy).

Interactions: Hover over nodes for details. Click to highlight connections. Drag to pan. Scroll to zoom.

Built with universal-blockchain-decoder. Graph visualization shows chain relationships across the blockchain ecosystem.
