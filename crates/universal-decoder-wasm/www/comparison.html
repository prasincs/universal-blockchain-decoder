✅ Universal Properties (Same in TxIR)

  • Both have authorization (signatures proving validity)
  • Both perform value transfer (Operation::Transfer)
  • Both modify state (UTXO set or account balances)
  • Both have fees (different mechanisms)
  • Both have replay protection (different mechanisms)
  • Both have transaction IDs (different hash algorithms)

⚡ Key Differences (Preserved in Chain-Specific Data)

  • State Model: UTXO (stateless) vs Account (stateful)
  • Structure: Inputs/Outputs vs From/To/Nonce
  • Fee Calculation: Implicit vs Explicit gas
  • Parallelization: Parallel vs Sequential

TxIR Type Explorer

Explore the universal transaction intermediate representation that unifies all blockchains

▼ TxIR<'a, V: u8> Universal transaction representation
▼ chain: ChainRef Which blockchain
id: u64 // Chain ID (Ethereum = 1, Bitcoin = 0)
name: String // Human-readable name
family: ChainFamily // UTXO/Account/Instruction/Privacy
network: Option<String> // mainnet/testnet
▼ metadata: TxMetadata Context information
tx_hash: Vec<u8> // Transaction ID
block_height: Option<u64> // Block number
timestamp: Option<u64> // Unix timestamp
size: usize // Transaction size in bytes
extra: String // Chain-specific JSON metadata
▼ authorization: AuthorizationPackage Who signed this?
signatures: Vec<Signature> // Digital signatures
public_keys: Vec<PublicKey> // Signing keys
signature_scheme: SignatureScheme // ECDSA/EdDSA/Schnorr
▼ operations: Vec<Operation> What does it do?
Transfer // Send value A → B
ContractCall // Execute smart contract
ContractDeploy // Deploy new contract
Stake // Staking operations
Generic // Chain-specific operations
▼ state_deltas: StateDeltas How does state change?
inputs: Vec<InputReference> // UTXO inputs (Bitcoin)
outputs: Vec<OutputValue> // UTXO outputs (Bitcoin)
account_changes: Vec<AccountChange> // Account changes (Ethereum)
▼ privacy: Option<PrivacyMetadata> Privacy features (optional)
features: Vec<PrivacyFeature> // HiddenSender, HiddenAmount, etc.
observability: ObservabilityLevel // FullyPrivate, Partial, Observable
viewing_key: Option<ViewingKey> // For selective disclosure
