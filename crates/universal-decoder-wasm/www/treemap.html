About This Visualization

This treemap shows the Universal Blockchain Decoder's coverage across **1575 mainnet blockchains** (4900+ including testnets). Each rectangle represents a chain family, ecosystem, or individual blockchain, sized by your selected metric.

Note: Counts reflect mainnet chains only. The embedded registry contains 2397 EVM chains total (1453 mainnets + 944 testnets).

Hierarchical Structure (Mainnets Only)

  • EVM Ecosystem (1453 mainnets): OP Stack (~50), Arbitrum Orbit (~30), Polygon CDK (~20), zkEVM (~12), Standard EVM (~1341)
  • Cosmos SDK (~100 mainnets): IBC-connected chains with Tendermint consensus
  • SVM (1 mainnet): Solana Virtual Machine - parallel transaction processing
  • Other Account-Based (~10 mainnets): Aptos, Sui, NEAR, Algorand, Stellar, XRP, Tron, Polkadot, etc.
  • UTXO (9 mainnets): Bitcoin, Litecoin, Dogecoin, Cardano, etc.
  • Privacy (2 mainnets): Zcash, Monero

Current metrics are mock data for demonstration. In production, this could be connected to live sources:

  • TVL: DeFiLlama API for real total value locked
  • Transaction Volume: Chain-specific APIs or indexers
  • Active Addresses: On-chain metrics

Navigation: Click on ecosystem groups (e.g., "EVM Ecosystem") to drill down into sub-ecosystems (e.g., "OP Stack"), then into individual chains. Click "All Chains" breadcrumb to return to top level.
